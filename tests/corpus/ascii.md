# ASCII corpus

Plain ASCII text keeps the PDF in the standard fonts: Helvetica, Helvetica-Bold,
Helvetica-Oblique and Courier, with no embedded font program.

## Emphasis and code

`inline code()` next to a [link to the project](https://github.com/Butterski/rayomd).
